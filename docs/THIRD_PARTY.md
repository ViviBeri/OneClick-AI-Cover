# Third-party components and licenses

This project is a local integration scaffold. Review each dependency's current license and model terms before redistributing binaries, weights, or builds.

- **Gradio** — application UI; see the Gradio project license.
- **Demucs** — vocal separation; see the Demucs repository and its dependency licenses.
- **RVC WebUI backend** — downloaded at a pinned upstream commit by the Windows setup script; review its license and every bundled dependency.
- **PyTorch and audio libraries** — review their individual licenses.
- **Voice models, HuBERT/RMVPE assets, and other weights** — may have separate terms and are not included in this repository.

The MIT license in this repository applies only to original project code. It does not grant rights to third-party software, model weights, songs, recordings, or voices.
