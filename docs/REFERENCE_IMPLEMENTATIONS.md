## Required licence review before adoption

For every code or asset candidate, record and verify:

1. Exact upstream commit/tag and retrieval date.
2. Code licence and required attribution, copyright, NOTICE and source-disclosure obligations.
3. Copyleft scope and whether it can attach to linked modules, plugins, subprocesses or a network-served application.
4. Model-weight, checkpoint, index, dataset and other asset licences separately from the code licence.
5. Redistribution, commercial-use, modification and hosted-service restrictions.
6. Dependency licences and platform/runtime constraints.
7. The exact files or concepts intended for reuse, and what will explicitly not be copied.

Do not treat a repository-level licence badge as proof that model weights, datasets, checkpoints or third-party dependencies share that licence. No candidate is approved for shipping until this review is complete.
